# HanZiKit

Projet personnel en cours de développement. 
Il s'agit d'un compilateur codé en C++ pour un langage dédié (DSL) visant à faciliter la création d'outils d'apprentissage du chinois mandarin.

## État d'avancement
* Le pipeline de base (Lexer, Parser, AST) est implémenté.
* Le programme est capable d'enrichir l'AST via le dictionnaire CC-CEDICT et d'exporter les données en JSON.
* Le rendu visuel actuel est une ébauche réalisée à l'aide de templates HTML/JS/CSS externes.

*Note : Ce dépôt sert principalement de terrain d'expérimentation pour explorer l'architecture des compilateurs. De nombreuses fonctionnalités (comme la gestion avancée par DAG ou un émetteur complet) sont encore à venir.*
